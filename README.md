# Glassmorphism Calculator

A responsive, modern web calculator built with **HTML5**, **CSS3**, and **Vanilla JavaScript** as **Task 2** of the CodeAlpha Frontend Development Internship.

## Features
- **Glassmorphism UI:** Frosted-glass card design with `backdrop-filter`, CSS Grid keypad layout, and distinct styling for numbers, operators, and action buttons.
- **Core Arithmetic Operations:** Supports addition (`+`), subtraction (`-`), multiplication (`×`), division (`÷`), and percentage (`%`).
- **Smart Input & State Management:** Prevents duplicate decimal points (`.`), supports chained calculations, and includes Clear (`C`) and Delete (`DEL`) controls.
- **Dual Display Screen:** Shows the active operand in the main display and tracks the previous operand with the selected operator above it.

## Tech Stack
- **HTML5** — Semantic structure, display screen, and button grid (`data-action` attributes)
- **CSS3** — Flexbox, CSS Grid, and Glassmorphism styling
- **JavaScript (ES6+)** — State-based calculation logic, event listeners, and dynamic screen updates
